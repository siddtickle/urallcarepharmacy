# AllCare Pharmacy website

Website for AllCare Pharmacy, Orthopedic and Medical Supplies (Oxon Hill, MD), with Slack automation:

- **Contact Us** messages go to `#website-inquiries`; replying in the thread emails the customer.
- **New Google reviews** go to `#google-reviews`; replying in the thread posts the public reply on Google.
- **Website changes** are requested in `#website-changes`; Claude makes the change, posts a preview with screenshots, and an admin presses *Merge & deploy*.

Setup and day-to-day use: [SETUP.md](SETUP.md).
